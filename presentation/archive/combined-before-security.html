QA: proposed setup

  • QA requests an environment from an approved template,
    choosing the product, release, size and expiry.
  • DevOps maintains the templates and limits.
    Start with DevOps approval of every final environment plan.
  • Automation runs Terraform with a scoped identity,
    then GitOps deploys the selected application versions.
  • QA receives the URL and status, then runs the tests.
    Approved expiry starts cleanup; failures go to DevOps.

Choosing what to test

A release manifest is a file that describes the test setup.

Release manifestWhat we record
Product and targetThe product, environment profile and instance name.
VersionsExact application images and infrastructure template version.
SetupSettings, dependencies, test data, accounts and secret references.
Test and lifecycleRequired tests, owner, capacity, budget and expiry or retention.

Use the same manifest to recreate the setup and identify the versions tested.

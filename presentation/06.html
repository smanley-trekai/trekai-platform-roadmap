Normal access and temporary elevation

TermWhat it means
Normal accessThe approved permissions needed for everyday work.
Entitlement or eligibilityA predefined task, resource scope, role, duration and approval rule.
Eligible people can request or activate it.
Temporary grantOne approved period of extra access.
Verify the intended action works, then verify access ends.
PAM means Privileged Access Management.
Temporary access still follows the normal change and incident rules.

PAM: the mechanism for each platform

PlatformProposed implementation
Google CloudUse Google Cloud Privileged Access Manager entitlements
for supported IAM roles at the agreed resource scope.
GitHubEvaluate Entra PIM for Groups with the selected GitHub mapping.
Prove team-role activation, expiry and removal timing in a pilot.
Entra administrationUse Entra Privileged Identity Management (PIM)
for eligible directory admin roles where supported.
Google Cloud PAM manages Google IAM access.
GitHub needs its own tested elevation path.

How we prove access works

TestExpected result
Normal workThe user can perform agreed daily tasks.
Restricted resources and elevated actions remain denied.
Pending or declined requestThe request adds no extra access.
Approved activationOnly the approved role and resource become available.
Audit records identify the requester, approval and grant.
Expiry or removalThe elevated action becomes denied while valid normal access remains.
Measure propagation delays and test early ending too.

Test human sign-in with real pilot users. A service-account test cannot prove that experience.
